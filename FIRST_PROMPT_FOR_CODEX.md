# Prompt inicial para Codex

Trabaja en el repositorio GAPSI Sentinel.

Lee primero, en este orden:

1. `AGENTS.md`
2. `README.md`
3. `docs/DEFINITION_OF_DONE.md`
4. `docs/product/PRODUCT_BRIEF.md`
5. `docs/product/DOMAIN_GLOSSARY.md`
6. `docs/architecture/ARCHITECTURE_DECISIONS.md`
7. `docs/tasks/TASK-001.md`

Tu única tarea autorizada es **TASK-001 — Fundación técnica del MVP**.

Antes de modificar archivos:

- inspecciona el repositorio y el entorno;
- resume el objetivo;
- presenta un plan breve;
- enumera las decisiones técnicas que tomarás;
- señala supuestos y riesgos;
- indica qué comandos usarás para validar.

Después implementa TASK-001 completamente.

Restricciones:

- no construyas módulos futuros;
- no configures servicios de pago;
- no uses secretos reales;
- no despliegues a producción;
- no elimines archivos fuera del repositorio;
- no declares éxito sin ejecutar las validaciones disponibles.

Al terminar entrega:

1. resumen funcional;
2. archivos principales creados o modificados;
3. comandos ejecutados;
4. resultado de lint, typecheck, pruebas y build;
5. decisiones tomadas;
6. riesgos o pendientes;
7. siguiente tarea recomendada, sin implementarla.
