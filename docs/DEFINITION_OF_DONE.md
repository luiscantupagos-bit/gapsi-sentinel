# Definition of Done

Una tarea se considera terminada únicamente cuando cumple lo aplicable:

## Funcional

- Cumple todos los criterios de aceptación.
- No agrega comportamiento fuera del alcance.
- Los errores previsibles tienen respuesta clara.
- Los estados vacíos y de carga son visibles.

## Datos y seguridad

- La migración o cambio de esquema está documentado.
- Se mantiene el aislamiento entre organizaciones.
- La autorización se valida en servidor.
- No se exponen secretos ni datos sensibles.
- Las entradas se validan.

## Calidad técnica

- Typecheck aprobado.
- Lint aprobado.
- Pruebas relevantes aprobadas.
- Build aprobado.
- No hay errores conocidos ocultos.
- El código nuevo sigue los patrones del repositorio.

## Experiencia

- Responsive en escritorio y móvil.
- Etiquetas, botones y errores son comprensibles.
- Navegación por teclado y contraste básico considerados.
- El idioma inicial es español.

## Entrega

- Resumen de archivos modificados.
- Evidencia de validaciones ejecutadas.
- Riesgos y pendientes declarados.
- Documentación actualizada cuando cambian reglas o arquitectura.
