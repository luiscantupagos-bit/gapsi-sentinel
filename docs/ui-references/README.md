# Referencias visuales (mockups)

Mockups de referencia para la interfaz de GAPSI Sentinel. Se usan como guía de
estructura, jerarquía y estilo; **no** definen los datos (los datos siempre son
reales del sistema).

## Dashboard Ejecutivo

`dashboard-ejecutivo-final.jpeg` — referencia visual final del **Dashboard
Ejecutivo** (versión con tema oscuro). Su implementación en la app **adapta** el
diseño al **tema claro** de GAPSI Sentinel (sidebar azul marino, topbar clara,
fondo gris muy claro, tarjetas blancas, bordes sutiles) conservando los acentos
de color (verde/ámbar/rojo/azul) y la distribución ejecutiva.

> Nota: el mockup se recibió como imagen en la conversación. Si el archivo
> `dashboard-ejecutivo-final.jpeg` no está presente en esta carpeta, colócalo aquí
> para la comparación por archivo; la implementación ya está hecha con base en esa
> referencia (ver `docs/ui/UI-MOCKUP-IMPLEMENTATION-NOTES.md`).
